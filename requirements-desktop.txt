# requirements-desktop.txt — the PyInstaller SIDECAR subset (Tangent Agent desktop).
#
# The local daemon boots the existing Flask app.py under waitress on 127.0.0.1, parses
# local files, and BUILDS deliverables on-device — but it never talks to Postgres/Redis
# and never runs Alembic. Version floors are copied verbatim from requirements.txt so dev
# and desktop resolve compatibly (CI asserts this in tests/test_desktop_packaging.py).
#
# EXCLUDED (server-only — pulling them would bloat the bundle, and PyInstaller's spec
# `excludes` them transitively):
#   psycopg2-binary  → Postgres driver; the daemon uses bundled stdlib sqlite3.
#   gunicorn         → fork-based WSGI server; the daemon uses waitress (Windows-friendly).
#   redis            → shared rate-limit/RPM counters across workers; single-user daemon
#                      runs flask-limiter on memory:// (no redis needed).
#   alembic          → Postgres migrations; SQLite uses create_all + the column shim.
#   sentry-sdk       → optional cloud error tracking; off by default, not for the device.
#
# NOTE on keys: NO provider/Anthropic/DeepSeek/Qwen key is ever bundled. `anthropic` is
# listed only because agent_team/llm.py imports it at module load; the daemon NEVER
# constructs an Anthropic client (inference is cloud-proxied through /v1 by RemoteRouter).
