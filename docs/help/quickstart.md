# 快速上手

从注册到收到第一份《经营周报》，只需要 5 步，全程约 10 分钟。

## 1. 注册账号

- 点击右上角 **Sign up**，填写姓名、邮箱、密码和手机号；
- 输入短信验证码完成验证（本地开发环境下验证码会打印在服务器控制台）；
- 注册成功后会展示你的 API Key —— **只显示一次**，请妥善保存（仅调用网关接口时需要，网页使用不需要）。

## 2. 完善公司信息（新手引导第 1 步）

首次登录会自动打开「新手引导」：

- 填写公司名称；
- 选择所属行业（跨境电商 / 贸易公司 / 通用）—— 系统会按行业套用对应的报告模板包（必备指标、行业基准、报告结构）。

## 3. 上传数据，或直接用示例数据（第 2 步）

- 上传一份近期的经营数据文件，支持 **Excel（.xlsx）/ CSV**；
- 没有现成数据？点 **「用示例数据体验」**，系统会载入一份内置的 12 周跨境电商销售数据，效果完全一样。

## 4. 确认 KPI 列名（第 3 步），生成第一份报告（第 4 步）

- 系统会根据文件表头自动猜测每一列对应的指标（销售额、订单数、广告费……），确认或修改后一键保存；
- 点 **「生成第一份报告」**，页面上能实时看到 AI 团队的工作过程；几分钟后报告生成，可在线阅读、下载品牌版 PDF。

## 5. 设置每周定时（第 5 步）

- 一键创建「每周一早上 8 点」的定时任务，并选择送达方式（邮箱 / 企业微信群机器人）；
- 之后每周一早上，AI 团队会自动用你最近上传的数据生成周报并送达——不需要再登录。

---

提示：随时可以在菜单的 **企业大脑** 里维护公司档案、KPI 映射、术语表和报告偏好；这些会让每一份后续报告更懂你的业务。遇到问题点右下角 **联系支持**。
