# 数据安全说明

你的经营数据是敏感资产。本页说明我们在每一层对它的保护方式。

## 存储加密

- 你上传的每个文件、系统生成的每份报告 PDF，落盘前都会用 **Fernet（AES-128-CBC + HMAC）** 加密；磁盘或备份泄露不会暴露明文内容；
- 加密密钥只存在于服务器环境变量中，支持多密钥轮换；密钥从不写入代码、日志或数据库。

## 访问控制

- 报告与文件下载必须登录，且服务端逐次校验归属——任何账号访问他人报告一律返回 403；
- 管理后台（/admin）仅对管理员邮箱白名单开放；
- 「全端退出」会立刻吊销该账号在所有设备上的登录态。

## 凭据保护

- 密码只以加盐哈希（bcrypt）存储，任何人（包括我们）都无法还原明文；
- 短信验证码只存哈希，5 分钟过期，错 5 次作废；
- 你的 API Key 只在创建时展示一次，系统仅保存其 SHA-256 指纹；
- 邮件、企业微信 webhook 等推送凭据从不写入日志或数据库明细。

## 审计与风控

- 登录、充值、下载、管理操作均写入只增不改的审计日志（不含任何敏感值）;
- 平台对上游模型支出设有熔断器，异常消耗会自动停止服务并告警，防止失控调用。

## 数据使用边界

- 你的数据只用于为你生成分析与报告，**不会** 用于训练模型，也不会提供给其他客户；
- 「企业大脑」中的档案、指标、术语只注入你自己账号的分析流程；
- 需要彻底删除数据时，联系支持即可（我们会同时清理上传文件、报告与指标库）。

如对安全有更高要求（私有化部署、专属密钥等），请通过右下角 **联系支持** 与我们沟通。
