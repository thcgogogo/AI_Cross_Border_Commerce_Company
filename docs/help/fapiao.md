# 发票说明

## 哪些订单可以开发票？

- **已支付成功** 的订单（充值或订阅）均可申请发票；
- 未支付、支付失败的订单不能申请；已全额退款的订单不再开具。

## 如何申请

1. 登录后进入控制台的 **「订单与发票」**；
2. 在已支付订单上点 **「申请发票」**；
3. 填写：发票抬头（公司全称）、税号（统一社会信用代码，18 位）、接收邮箱（默认账号邮箱）；
4. 提交后状态显示「待开具」。

## 开具与送达

- 当前为人工开票流程：财务每个工作日处理一次申请，一般 **3–5 个工作日** 内开出；
- 开具完成后会发邮件通知你（含抬头、税号、订单信息确认）；
- 电子发票直连开票（百望/诺诺等）已在规划中，上线后将即时开具并自动发送。

## 常见问题

**抬头/税号填错了？**
若申请被驳回（会注明原因），修改信息后可对同一订单重新提交；若已开具，请联系支持换开。

**一个订单能开多张吗？**
不能。一个订单对应一张发票，金额为订单实付金额。

**可以开个人抬头吗？**
目前仅支持企业抬头（需要税号）。个人抬头需求请联系支持。

**多个订单能合并开一张吗？**
暂不支持合并开票，请按订单分别申请；批量需求请联系支持人工处理。

其他开票问题，点右下角 **联系支持**。
